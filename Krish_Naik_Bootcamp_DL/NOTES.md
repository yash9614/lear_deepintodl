# Key Takeaways from Krish Naik DL Bootcamp

## RNNs
- Simple RNN for sequence data (e.g., IMDB sentiment).
- Issues: Vanishing/exploding gradients, limited long-term memory.
- Solutions: LSTM (gates: forget, input, output), GRU (simplified).
- Bidirectional RNN for context from both directions.

## Attention & Transformers
- Attention mechanism: focus on relevant parts of sequence (keys, queries, values).
- Encoder-Decoder for Seq2Seq (e.g., translation).
- Transformers: self-attention, multi-head, positional encoding – foundation for modern LLMs.

## ANN Example
- Customer churn classification with feature engineering (label/one-hot encoding, scaling).
- Hyperparameter tuning and deployment via Streamlit.
