## Q1.

How does GridSearchCV determine the best hyperparameters for a model?

- By consulting expert recommendations
- By using default parameters only
- By selecting random combinations to minimize time
- By testing every possible combination in the specified parameter grid

**Answer:** By testing every possible combination in the specified parameter grid

---

## Q2.

You are an environmental data scientist building a machine learning model to predict the tsunami in a specific region. Which model metric would you give the highest importance?

- Precision
- Recall
- Accuracy
- Number of Likes on Your LinkedIn Post

**Answer:** Recall

---

## Q3.

Which metric on the ROC curve is directly affected by changing the threshold for classifying a positive class?

- The precision of the model
- Only the area under the curve
- The fate of the Humans
- Both true positive rate and false positive rate

**Answer:** Both true positive rate and false positive rate

---

## Q4.

What type of machine learning algorithm is a random forest?

- Clustering algorithm
- Regression and classification algorithm
- Reinforcement learning algorithm
- Random Rocker Algorithm

**Answer:** Regression and classification algorithm

---

## Q5.

What parameter in DBSCAN determines the maximum distance between two points for them to be considered as part of the same neighbourhood?

- minPts
- eps
- corePts
- distance

**Answer:** eps

## Q6.

Which technique is commonly used to normalize different scales of feature values in machine learning preprocessing?

- Clustering
- Min-Max Scaling
- One-Hot Encoding
- Data Dance

**Answer:** Min-Max Scaling

## Q7.

Which linkage method in hierarchical clustering considers the shortest distance between any two points in different clusters?

- Average Linkage
- Single Linkage
- Complete Linkage
- Love Linkage

**Answer:** Single Linkage

## Q8.

Why might one choose to use a random forest over a single decision tree?

- For a simpler explanation of the model’s decisions
- To decrease the accuracy for more stable predictions
- Because he/she hates being single
- To reduce the risk of overfitting associated with single decision trees

**Answer:** To reduce the risk of overfitting associated with single decision trees

## Q9.

What is the main benefit of Stratified K-Fold Cross-Validation?

- Increases computational speed
- Ensures representative folds by class percentage
- Allows more folds
- It crosses the speed limit every time

## Q10.

Why is a high VIF problematic in a regression model?

- It indicates that the feature is less important to the model
- It implies that the model will be extremely accurate
- It shows that the data has no interest in being trained
